# SPRINT_5
# UI-автотесты для сервиса «Доска»

## Описание проекта
Данный проект содержит набор автоматизированных UI-тестов для учебного сервиса «Доска» (https://qa-desk.education-services.ru/).  
Тесты покрывают функциональность регистрации, авторизации, выхода из системы и создания объявлений.

## Требования
- pytest==7.4.0
- selenium==4.15.0
